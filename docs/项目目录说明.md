## 2. 分层架构

```text
浏览器
  -> FastAPI 同源前端
  -> FastAPI 路由层 api/
  -> 业务服务层 service/
  -> SQLite

智能对话请求
  -> FastAPI Dify 代理
  -> Dify 工作流
  -> Dify HTTP 工具
  -> FastAPI 权限与业务接口
  -> SQLite
```

职责边界：

- Dify：意图分类、知识库检索、LLM 话术组织。
- FastAPI：令牌、角色权限、数据归属、确定性规则、SQL 和业务状态机。
- SQLite：业务数据持久化。
- Dify 不直接连接 SQLite。
